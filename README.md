# 🎧 Automatic Roll-Back Wired Earphone Container

## 📌 Project Overview
The Automatic Roll-Back Wired Earphone Container is a smart solution designed to solve the common problem of tangled and messy wired earphones. It features an automatic retractable mechanism that smoothly rolls the earphone wire back into the container after use. The project improves portability, cable management, and user convenience while helping to protect earphones from damage.

## ❗ Problem Statement
Wired earphones often create issues such as:

- 🔄 Earphone wires getting tangled
- ⚠️ Increased chances of cable damage
- 🎒 Difficulty in storing and carrying earphones
- ⏳ Time wasted untangling wires
- 📉 Reduced earphone lifespan

## 💡 Proposed Solution
This project introduces an automatic roll-back mechanism that retracts earphone wires into a compact container after use. It helps users keep earphones organized, protected, and easy to carry.

## ✨ Features
- 🔁 Automatic wire roll-back mechanism
- 🚫 Prevents cable tangling
- 📦 Compact and portable design
- 👍 User-friendly operation
- 🛡️ Protects earphones from damage
- 🎨 Adjustable color customization
- 🖌️ Multiple pattern and texture options
- 🌈 Custom LED themes and effects
- 🎧 Easy storage and handling

## ⚙️ Working Mechanism
The system works using a retractable spool mechanism. When the user pulls the earphone wire, it extends for usage, and after use, the wire automatically retracts back into the container for organized storage.
